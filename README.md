# FrutoCerto

Protótipo feito em equipe durante um hackathon. A ideia era aproximar quem produz fruta de quem compra, sem atravessador no meio.

São dois lados do mesmo app:

**Cliente** (`cliente/`)
- Página inicial com as frutas da época
- Busca de frutas e produtores
- Chat com o produtor
- Acompanhamento dos pedidos
- Conteúdo para aprender a cultivar
- Configurações da conta

**Produtor** (`produtor/`)
- Pedidos recebidos
- Busca
- Controle de estoque
- Resumo financeiro

O pitch que apresentamos no hackathon está em `cliente/pitchleo-1.pdf`.

## Tecnologias

HTML, CSS e JavaScript. Sem back-end: as telas são o protótipo navegável da ideia.

## Como abrir

Baixe o repositório e abra `cliente/index.html` ou `produtor/index.html` no navegador.
